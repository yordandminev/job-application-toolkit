# Fit analysis

## Inputs
1. The job posting (URL or saved PDF). Note location, level, language, deadline and compensation if stated. If no deadline is shown, say so.
2. The latest master CV and the content library (alternative summaries and bullets by role type).
3. The story bank (STAR stories) and the memory notes on facts I have confirmed or ruled out.

## Steps
1. List the posting's requirements in its own order of emphasis (what it leads with matters most).
2. For each requirement, mark **Strong / Good / Partial / Gap** and cite the exact CV or library evidence. Never cite something that is not in a source.
3. Score 0-10. Weigh the screen (keywords and hard requirements a recruiter checks first) more than interview potential.
4. Write **Risks the CV can't fix**: location and work eligibility, level and pay, language, industry.
5. Write an honest **culture fit** view: what supports it and what a reviewer will doubt.
6. Recommend: apply, apply with caveats, or skip. A skip is a valid answer.
7. Save as `<Company>_<Role>_Fit.md` in the role folder, using `templates/fit_analysis_template.md`.

## Rules
- Never list a tool or method I have not used, even if it would raise the score. Record it as a gap.
- Re-score when I add a new fact, and note what moved the score.
- Give pros and cons when I push back; don't simply agree.
