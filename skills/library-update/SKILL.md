# Library update

## When
Right after I confirm an application was submitted, never before (drafts change until the last minute).

## Steps
1. Compare the submitted CV, letter and answers against the content library and story bank.
2. Add every new piece, labelled with company, role type and date:
   - new summaries or headlines,
   - new or reworded bullets,
   - new letter openings, bridges, proof points and closings,
   - new form answers.
3. Add new facts I gave during drafting to the story bank (with their exact numbers and scope), and update any older variant they correct.
4. Record what I rejected and why (e.g. "too cheesy", "too casual", "not accurate"), so the same wording is not proposed again.
5. Save the updated library as a new dated version and move the previous one to `Old versions/`.
6. Update the application tracker: status, date, materials sent.

## Rules
- Only the final, submitted wording goes in as "used". Unused drafts can be kept, clearly marked as not sent.
- Never overwrite an approved number with a new one without checking which is right.
