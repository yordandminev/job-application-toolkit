# Role discovery

## Inputs
- Search profile: target role families, seniority, locations (including remote rules), languages and hard no-gos (e.g. a required language I don't speak).
- Sources: job-alert emails (LinkedIn, Indeed), job boards and company career pages. Many boards block automated reads; when a page can't be read, ask me to save it as PDF instead of guessing its content.

## Steps
1. Collect new postings since the last run and drop duplicates (same company, title and location).
2. Screen out hard no-gos first: required languages, junior or intern levels, locations or work-permit rules that don't fit.
3. For each remaining role, record company, title, location, posting URL, deadline (if stated) and the 3-5 requirements a screener will check.
4. Give each a quick fit estimate (high, medium, low) with one line on the main match and the main gap.
5. Present a ranked shortlist and recommend which 2-3 deserve a full fit analysis. Flag deadlines within a week.
6. Add the shortlisted roles to the application tracker with status "Shortlisted".

## Rules
- Never apply or contact anyone; I decide which roles to pursue.
- Quote requirements from the posting, don't paraphrase them into something easier to match.
- When a posting can only be read in summary, say so in the record.
