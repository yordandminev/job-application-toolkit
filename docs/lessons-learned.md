# Lessons learned

A log of corrections that shaped the system. Each one became a rule in a skill, the writing rules or the agent's memory, so it never has to be made twice.

| # | What went wrong | Rule it created |
|---|---|---|
| 1 | The agent added "using AI" to a negotiation story to make it richer. It wasn't true. | **Facts only.** Rephrase existing facts; ask for anything new. The most important rule in the system. |
| 2 | Two separate wins were written as one cause and effect. | Separate wins stay separate. |
| 3 | A summary headline copied the posting's job title. | Headline = honest label; mirror the posting in sentence 2. |
| 4 | An opening built on a clever slogan read as "very cheesy". | Factual openings: what I do, then my role in the story. |
| 5 | "17+ years" and "leader" on a CV for a flat, title-less startup. | Startup signals mean no years and "builder" instead of "leader". |
| 6 | A "why us" answer restated the mission and was "very boring". | Personality and a true, light joke beat mission praise. |
| 7 | Efficiency numbers (hours saved per week) stood alone and read as admin work. | Always pair efficiency with an outcome. |
| 8 | A bullet grew to four lines after a late edit. | Re-render and check layout after every edit, not just the first draft. |
| 9 | A file written to a synced folder silently kept the old version. | Verify every saved file by checksum after writing. |
| 10 | Old cloud copies of the CV were used as the base. | One local, dated source of truth; older versions in `Old versions/`. |
| 11 | A detail from another chat appeared in a draft without confirmation. | Context from elsewhere is a lead, not a fact; ask before using it. |
| 12 | A form answer mixed the problem, method and fix in one paragraph. | One paragraph per idea; name the edge case explicitly. |
| 13 | The agent agreed with every edit request. | Every edit request gets pros, cons and an honest recommendation. |
